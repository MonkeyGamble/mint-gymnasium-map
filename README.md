# MINT Gymnasium Map

Интерактивная карта гимназий Nordrhein-Westfalen и Rheinland-Pfalz на Google Maps.

## Возможности

- 138 гимназий NRW: исходные 100 и 38 дополнительных MINT-EC; подтверждённое членство MINT-EC у 96 школ.
- 21 гимназия Rheinland-Pfalz из официального списка сети MINT-EC, с местами в MINT-рейтинге земли.
- Переключение федеральной земли, поиск, фильтр по городу и «Только MINT-EC».
- Подсветка маркера при наведении или выборе школы в списке.
- Карточки со ссылками на официальные сайты гимназий.

В обеих землях номера обозначают места в общем MINT-рейтинге schulen.de (государственные и частные школы всех типов). Новые школы добавляются при подтверждённом членстве MINT-EC и месте 1–300 в своей земле. Рейтинг не ограничивается членами MINT-EC. Школы с одинаковым местом имеют разные стабильные ID, поэтому подсветка не путает их.

## Запуск

Проект использует обычные HTML, CSS и JavaScript, сборка и установка зависимостей не нужны.

1. Скопируйте `dist/maps-config.example.js` в `dist/maps-config.js`.
2. В новом файле задайте `googleMapsApiKey` — ключ Google Maps JavaScript API. Файл исключён из Git.
3. Запустите локальный HTTP-сервер из корня репозитория:

```sh
python -m http.server 8000 --directory dist
```

4. Откройте http://localhost:8000/.

Открытие HTML напрямую через `file://` не подходит: приложение загружает JSON через fetch.

Ключ из `maps-config.js` подключается автоматически при каждом открытии. Если файл не настроен, интерфейс предлагает ввести ключ и запоминает его в текущем браузере.

## Vercel

1. Импортируйте репозиторий `MonkeyGamble/mint-gymnasium-map` в Vercel.
2. Оставьте Root Directory в корне репозитория (`./`). Параметры сборки заданы в `vercel.json`.
3. Добавьте переменную окружения `GOOGLE_MAPS_API_KEY` со своим ключом для Production и Preview.
4. Нажмите Deploy. При сборке скрипт `scripts/build-config.mjs` создаст `dist/maps-config.js` из переменной окружения.
5. Разрешите итоговый домен Vercel в ограничениях HTTP referrers ключа в Google Cloud.

Ключ не хранится в GitHub. После публикации карта получает его автоматически. Изменение переменной окружения требует новой сборки. При подключённой Git-интеграции новые коммиты в `main` запускают обновление сайта.

## Размещение

Разместите содержимое `dist/` на статическом хостинге. Файл `maps-config.js` нужно добавить в окружение размещения отдельно; он не хранится в публичном репозитории.

В Google Cloud включите Maps JavaScript API и настройте допустимые HTTP referrers для домена размещения. Браузерный ключ доступен посетителям работающего сайта, поэтому ограничивайте его доменами и используемым API.

Исходная работающая версия: https://nrw-mint-gymnasien.fatuglyaces.chatgpt.site

## Данные и источники

Снимок данных: **7 октября 2026 года**.

- `dist/schools.json` — 138 гимназий NRW, из них 96 MINT-EC.
- `dist/rp-schools.json` — 21 гимназия MINT-EC Rheinland-Pfalz.
- `dist/data-sources.json` — источники, правила отбора, дата и проверка всех 132 записей сети в двух землях. Для каждой записи сохранены официальный ID, ссылки и причина включения/исключения.
- `dist/sources.html` — описание методики и ограничений для посетителей.
- NRW: https://schulen.de/toplisten/beste-schulen-nordrhein-westfalen-mint/
- RLP: https://schulen.de/toplisten/beste-schulen-rheinland-pfalz-mint/
- MINT-EC: https://netzwerkkarte.mint-ec.de/

При сверке сопоставлялись название и город/адрес школы; неоднозначные совпадения проверены вручную. Исходные 121 школа сохранены. Интегрированные Gesamtschulen исключены; уже присутствовавший самостоятельный гимназический филиал Ausonius-Gymnasium в KGS Kirchberg сохранён. Его Realschule отдельно не включается.

Max-Planck-Gymnasium Düsseldorf не включён: schulen.de ошибочно относит его к Baden-Württemberg, поэтому место в рейтинге NRW не подтверждено. Нельзя использовать позицию другой земли или выдумывать NRW-позицию.

Рейтинг отражает опубликованные предложения школ по MINT, а не качество обучения. Членство в сети MINT-EC и позиция в рейтинге schulen.de — разные показатели. При обновлении данных необходимо заново сверить каталог сети и рейтинг, не выводя членство только из названия школы или рейтинга.

## Проверка

```sh
node scripts/verify-data.mjs
node scripts/verify-interactions.mjs
node --check dist/app.js
```

Проверки не требуют Google API-ключа. Проверка взаимодействий использует тестовые DOM и Google Maps и проверяет создание всех маркеров, фильтры и подсветку. Она не заменяет визуальную проверку настоящей карты Google Maps.
